# Open Source Maintenance

This document tracks current maintenance priorities for the Huzur repository.

## Current priorities

- Improve README project status and roadmap sections.
- Add an Android build and release checklist.
- Improve automated tests and contributor documentation.
- Review service integrations before releases.
- Keep issues and pull requests organized for future contributors.

## Maintainer workflow

1. Review open issues regularly.
2. Prioritize fixes, documentation, tests, and release tasks.
3. Run local checks before merging changes.
4. Keep release notes and setup instructions up to date.
5. Document important decisions in the repository.
